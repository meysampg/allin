# PokerEquity resources

- `preflop169.bin`: heads-up preflop hand-vs-hand equity table, generated by `allin-tool gen-preflop` (M2.6).
  Loaded by `PreflopEquityTable.shared` via `Bundle.module` (subdirectory `Resources`). When the file is absent,
  `shared` is nil and preflop equity falls back to exact enumeration.
